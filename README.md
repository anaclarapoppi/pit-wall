# 🏎️ PIT WALL — GP DE SÃO PAULO

## 📌 Sobre o Projeto

O PIT WALL é uma página web temática sobre o Grande Prêmio de São Paulo de Fórmula 1. O projeto apresenta informações sobre a corrida, pilotos, classificação e venda de ingressos, utilizando um visual inspirado nas equipes e nos circuitos de automobilismo.

A página foi desenvolvida com HTML5 e CSS3, buscando reproduzir um layout moderno, organizado e responsivo.

## 🎯 Objetivo

O objetivo do projeto é colocar em prática os conhecimentos de HTML e CSS, criando uma página que apresente diferentes conteúdos de forma organizada e visualmente atrativa.

## 💻 Tecnologias Utilizadas

- **HTML5:** utilizado para estruturar os conteúdos da página.
- **CSS3:** utilizado para criar o design, as cores, os espaçamentos e a organização dos elementos.

## ⚙️ Funcionalidades e Elementos Implementados

- Cabeçalho com o título PIT WALL.
- Destaque principal do GP de São Paulo.
- Imagem de um carro de Fórmula 1.
- Grid de pilotos com números, nomes e equipes.
- Tabela de classificação dos pilotos.
- Área de ingressos com valores dos setores.
- Formulário para cadastro de interessados.
- Menu com links para navegar pelas seções.
- Layout com versão principal e prévia de celular.

## 📚 Recursos de CSS Trabalhados

Durante o desenvolvimento foram utilizados os seguintes recursos:

- `:root`: criação de variáveis para armazenar cores e facilitar a organização do CSS.
- `display: flex`: organização e alinhamento dos elementos.
- `grid-template-columns` com `auto-fit`: criação de grades que se ajustam automaticamente.
- `form-grid`: organização dos campos do formulário em colunas.
- `<table>`: estruturação da tabela de classificação.
- `@media`: adaptação do layout para diferentes tamanhos de tela.

## 🚀 Como Executar o Projeto

1. Baixe ou copie os arquivos do projeto.
2. Coloque `index.html`, `style.css` e `piloto.jpg` na mesma pasta.
3. Abra o arquivo `index.html` em um navegador.
4. Visualize a página do PIT WALL.

## 🧠 O Que Foi Aprendido

Com a realização deste projeto, foi possível aprender e praticar a criação de páginas web utilizando HTML e CSS. Também foi possível compreender melhor como organizar conteúdos com Flexbox e Grid, construir tabelas e formulários, trabalhar com imagens e utilizar media queries para adaptar a página a diferentes telas.

Além disso, o projeto ajudou a desenvolver a capacidade de reproduzir um modelo visual, organizar arquivos e combinar diferentes recursos de CSS para criar uma página mais completa e organizada.

## 🏁 Considerações Finais

O desenvolvimento do PIT WALL foi uma oportunidade de colocar em prática os conhecimentos adquiridos nas aulas de desenvolvimento web. O resultado foi uma página temática de Fórmula 1, com informações sobre o GP de São Paulo e diferentes elementos de HTML e CSS.
